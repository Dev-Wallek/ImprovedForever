# Features (shipped, per README.md / CHANGELOG.md / dist/curseforge/*.md)

- **Core**: button glyphs, configuration panel (double-tap Menu or `/if`), Bindings tab (controller press and keyboard/mouse press per binding), bag clean-up, touchpad corner actions (incl. double-tap; on SteamOS with Steam Input on, the touchpad's four areas are set as numpad 7 9 1 3 keys, see the README), other addons' windows that Escape closes join L2 / R2 beside the game's windows with a cursor, A, X and Circle in them (a General switch turns it off; not released yet), shared item verdict, bundled game data, a General switch that leaves the controller's buttons to the game.
- **Wheel**: radial wheels on R3 combos (defaults: L1 Quest Items, L2 Emotes, R1 Consumables); built-in wheels Quest Items (items a quest has you use or that start one), Consumables (food, drink, potions, bandages, scrolls, elixirs, flasks), Emotes, Group (pick a party or raid member, then cast a helpful spell on them, usable in combat), Improved Forever (our windows) and Camping (with the Camp module); custom wheels (spells, items, macros, emotes, chat phrases, totems, trinket swap, cancel buffs (not released yet)); recent action slot. Source: ImprovedForever_Wheel code (Wheel.lua, MyWheels.lua).
- **Vibration**: vibration on game events and spell casts, per-action patterns.
- **Minimap**: names beside minimap dots (herbs, ore, quests, NPCs, party), gathering alerts. Paused since WoW Forever's November 2026 update stopped addons reading the minimap (0.7.1 says so in game); back by itself once the game answers again. A square minimap setting (not released yet; it doesn't read the minimap).
- **Map**: peek map.
- **Chat**: pick a chat line and the links in it with the pad; Cross opens an item in the Wiki. An inline keyboard (LB + RB + Cross anywhere, a binding, or D-pad Down in the chat) laid out as the PS5's, low in the middle of the screen: Cross types, Square deletes, Triangle space, LB / RB move the cursor, LT / RT pick the channel (Global, Say, Yell, Party, Raid, Guild, Whisper, numbered channels), Start sends. The `/` key sits on the main layers; typing `/` offers the slash commands (and emotes) that start with it in a strip over the keyboard (D-pad Up from the top row, Left / Right, Cross completes), and Start runs a typed command. In the Global channel each key goes to the game as the keyboard's key and runs its binding (bags, map...), nothing is typed. Source: ImprovedForever_Chat code (ChatLines.lua, ChatKeyboard.lua).
- **Auction**: controller auction window, Buy/Sell/Owned pages, prices over time, tasks. Not released yet: with Auctionator installed, one full scan serves both; other addons read prices through `ImprovedForever.Auction.Price`, with Auctionator's for items only it has seen. When an item counts as better sold at the auction house is a setting (percent over the vendor's pay, default 25%; minimum gain, default none), and grey items worth more there are no longer junk.
- **Junk**: marks junk (quests, recipes, auction prices, class, soulbound), L2+L3 to mark, vendor Sell All Junk, Destroy panel, loot-window destroy when bags are full.
- **Addons** (not released yet): gathers each installed addon's slash commands, settings pages, addon compartment entries and LibDataBroker launchers per addon, leaving out the game's and libraries' commands, in an Addons tab of the Improved Forever panel (`/if addons`): a heading per addon, the D-pad moves through the entries, L1 / R1 jumps between addons, Cross runs a command as if typed or opens a settings page or launcher. A game window that opens while the panel is up gets the controller and the panel stays open behind it; it takes the controller back when that window closes, with L2 / R2, or when opened again. `/if addons dump` writes the list to the saved variables.
- **Wiki**: hold R3 on an item (or the middle mouse button) for drops, vendors, recipes, quests, auction prices; search any item by name; fishing waters. Data from QuestieDB.
- **Journal**: first-person diary of each day, per character, read as a leather book.
- **Fishing**: fishing mode (R2 twice or double right-click), per-cast scene, stringer, Fish Collection with first-catch cinematic, camera framing; mouse fishing.
- **Camp**: sitting by a campfire as a cutscene.
- **Immersion**: HUD rework: target header, player ring (movable and resizable), header (movable), spell-diamond gamepad bar, party/pet cards, nameplates (name font and size), debuffs and cast bars under nameplates, recent loot tiles, NPC subtitles (stay off when DialogueUI is installed), first-time tour (`/if tour`). Needs Journal and Spoken.
- **QuestTracker**: rebuilt objective tracker with sorting (zone, level, title, distance, completed), completion sound, full pad support.
- Square shoots your wand (Core 0.11.0; off by default since Core 0.12.1, a General switch).
